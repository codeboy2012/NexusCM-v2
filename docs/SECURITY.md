# Security Policy

## Supported Versions

During development, only the latest commit is supported.

Stable releases will include version support information.

---

## Reporting Security Issues

Please do not create public GitHub issues for security vulnerabilities.

Instead, contact the maintainers privately.

---

## Best Practices

- Enable HTTPS
- Keep Docker updated
- Rotate secrets
- Use strong passwords
- Enable MFA where possible
- Backup regularly

---

## Security Goals

- Secure defaults
- Principle of least privilege
- Minimal exposed ports
- Container isolation
