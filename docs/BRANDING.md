# Branding

## Overview

NexusCM was designed to be fully customizable.

Every deployment should be able to represent its own identity while maintaining compatibility with the platform.

---

# Branding Assets

branding/

```
fonts/
icons/
logos/
themes/
wallpapers/
```

---

# Logos

The default NexusCM logo is included within:

branding/logos/

Future releases may include:

- SVG
- PNG
- Dark Mode
- Light Mode
- Monochrome

---

# Themes

Themes are stored inside:

branding/themes/

Themes may customize:

- Colors
- Typography
- Backgrounds
- Icons
- Client Appearance

---

# Wallpapers

Wallpapers are used by:

- Login Pages
- Cinny
- Website
- Dashboard

---

# Fonts

Fonts should be licensed for redistribution.

Avoid proprietary fonts unless the user provides their own.

---

# Client Branding

The customized Cinny client may include:

- Logos
- Colors
- Wallpapers
- Login Screen
- Icons
- Default Theme

---

# Website Branding

The website should use the same design language as the client.

Consistency is preferred over complexity.

---

# Design Principles

- Modern
- Clean
- Minimal
- Accessible
- Responsive
- Professional
